# HostelFit MVP
Dependency-free browser MVP demonstrating the core HostelFit flow.

## Includes
Registration/login demo, profile + goal, hostel/mess, pre-loaded menu, meal logging, estimated calorie intake, workout logging, estimated expenditure, daily balance, weight history, and basic menu administration.

## Run
Open `index.html` in a modern browser. The same files are in `docs/` for GitHub Pages.

## Note
This is a frontend-only MVP using localStorage. It is not production-secure and does not replace the planned backend/database/authentication architecture.
